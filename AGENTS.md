# AI Agent Instructions

These instructions apply to every AI-assisted change in this repository.

1. Read `AI_SYNC.md` completely before analyzing, planning, or modifying repository code.
2. Inspect recent commits and open pull requests to confirm the ledger is not stale.
3. Claim or update the relevant item in the `AI_SYNC.md` Active Work Board before substantive work.
4. Avoid duplicating or contradicting work already recorded by another agent.
5. Use a focused branch and pull request unless the owner explicitly requires otherwise.
6. Update `AI_SYNC.md` in the same change with exact files changed, behavior changed, engineering rationale, tests, deployment impact, risks, and next actions.
7. Do not merge an AI-assisted change whose ledger entry is missing or materially incomplete.
8. Preserve paper-only and safety boundaries unless the owner explicitly changes them.

`AI_SYNC.md` is the authoritative shared context. Repository state and measured evidence take precedence when the ledger is stale; correct the ledger in the same change.
